# 星灯りの旅団 — Starlight Chronicle

日本語で遊べる、オリジナルのターン制ブラウザRPGです。

- 12ノードを接続した世界地図。隣接ノードだけを移動でき、ボス撃破で先のエリアが解放
- 3つの街（はじまりの村・月見の街ルナ・鍛冶の街ヴァル）と各地のボス
- 通常モンスター12種類＋ボス3種類、6種類の通常モンスターのシルエット
- 素材11種類。各モンスターに設定された4枠（コモン55%・アンコモン25%・レア8%・レジェンダリー2%）を独立抽選
- 素材の所持数・レアリティ表示と街での売却
- 攻撃・防御・回復・4種類の習得スキル
- 経験値、レベルアップ、ステータス上昇
- アイテムドロップ、武器・防具の購入と装備
- 宿屋、村長の討伐依頼、全滅からの復帰
- ブラウザのlocalStorageへの自動保存
- レスポンシブな画面と任意の効果音

## 遊ぶ

`dist/index.html` をブラウザで開きます。静的ホスティングでは `dist` を公開ディレクトリに指定してください。ビルドや依存パッケージは不要です。

ローカルサーバーを利用する場合:

```sh
python3 -m http.server 8080 --directory dist
```

Google Fontsは任意の外部フォントです。取得できない場合はシステムフォントで表示します。セーブデータはブラウザごとに保存されます。

## 操作

地図の線でつながった場所へ移動します。旗が現在地、家が街、塔がボスのノードです。未接続ノードへの移動や戦闘中の移動はできません。「探索する」で戦闘へ進みます。敵は3ターン目ごとに強攻撃を使います。「ぼうぎょ」でダメージを軽減しながらMPを回復できます。各エリアの魔物を4体倒すと、そのエリアのボスのノードでボスに挑戦できます。全滅時は最後に訪れた街へ戻ります。

スキルはLv.2・3・5・7で習得します。村で装備を買ったら「もちもの」から装着してください。5体討伐後、村の「依頼の報酬」で報酬を受け取れます。

## 検証

```sh
node --check dist/game.js
node tests/game.test.cjs
```

隣接移動・移動制限・全エリアの進行・ボス撃破・購入と装備・宿泊・全滅時の街への復帰・素材ドロップの確率境界・売却・旧セーブの移行・素材と現在地の保存を検証します。ブラウザでの表示・操作確認は未実施です。

既存のセーブデータはレベル・装備・進行を維持したまま新マップへ移行します。素材の抽選は独立しているため、何もドロップしない場合も、最大4種類を同時に入手する場合もあります。
