# 星灯りの旅団 — Starlight Chronicle

日本語で遊べる、オリジナルのターン制ブラウザRPGです。

- [ゲームを開く](https://starlight-chronicle-rpg.tomo27tomo84.chatgpt.site)（Sites・現在は所有者限定）
- [GitHub](https://github.com/tanaka27/gptwork-rpg-game)（開発ブランチ：`main`）

## 実装済みの内容

- 線でつながる12ノードのマップ、戦闘・素材入手などが起きる3工程の道中、宿屋・ショップを備えた3つの街
- 通常モンスター12種類、ボス3種類、最大4人対4体・素早さ順のターン制バトル
- レベルアップ、攻撃力・守備力・賢さ、物理／魔法・補助の5スキル
- 武器・防具の購入と装備、回復アイテム、討伐依頼
- 11種類の素材、4段階のレアリティと確率ドロップ、素材売却
- 自動保存、旧セーブの移行、確認付きのヘッダーリセットボタン
- 画面内で冒険・地図・もちもの・記録を切り替えるUIと任意の効果音

## 起動方法

Node.js 24以上を使用します。

```sh
npm ci
npm run content:sync
npm run dev
```

`http://127.0.0.1:4173/`がゲーム、`/admin/`がデータ管理画面です。ローカルDBは`.local/rpg.sqlite`へ作成し、マイグレーションを適用します。Playwrightは専用の`work/playwright.sqlite`を使い、普段のセーブには触れません。

本番は既存SitesのWorkers/D1で動作します。[データ管理画面](https://starlight-chronicle-rpg.tomo27tomo84.chatgpt.site/admin/)は所有者としてChatGPTにサインインして開きます。`npm run build`はフロントとAPIを含む`build/server/index.js`・ホスティング設定・DBマイグレーションを生成します。`dist/`の静的配信でも同梱定義によるローカルプレイは可能ですが、データ管理・クラウド保存にはAPIが必要です。

## データ管理と保存

右上の設定から「データ管理」を開き、公開版を下書きへ複製して編集します。キャラクター・モンスター・装備・スキル・マップ・ショップ・成長/戦闘設定を編集し、検証→保存→プレビュー→公開できます。公開済みの版は編集せず、以前の版の再公開も可能です。参照中のデータ削除は検証で拒否します。JSONの取り込み/書き出しにも対応します。

通常の進行は従来どおりブラウザへ自動保存します。「クラウドセーブ」から明示的にDBへ保存・復元できます。クラウド更新前の進行はDBの履歴へ、復元前のローカル進行はブラウザのバックアップへ残します。クラウドの既存データを無確認で上書きしません。リセットはこのブラウザの進行を対象とし、クラウドのバックアップは残ります。

定義プレビューは通常の進行とは別の保存キーを使用し、クラウドへ保存しません。戦闘中の定義をセーブへ保持するため、再読み込み中に公開データが変わってもその戦闘は同じ定義で続けます。

## 遊び方

画面下部の「地図」で世界地図、「もちもの」で装備・素材・スキル、「記録」で能力・依頼・ログを開きます。長い一覧は画面内でスクロールできます。世界地図の旗が現在地です。接続されたノードを選ぶと道中に出発します。冒険画面の「先へ進む」3回で到着し、途中で戦闘・何もなし・素材入手のいずれかが起きます。道中の戦闘は最大1回で、勝利・逃走後に続きを進められます。戦闘中以外は出発地へ引き返せます。到着した探索地では「探索する」で魔物と戦います。各エリアで4体倒し、ボスのノードに行くとボスに挑めます。ボス撃破で次のエリアが解放されます。

街で宿泊・買い物・素材の売却ができます。街名は背景の上部に表示し、宿泊成功の回復メッセージは街の画面に表示しません。街の「お店」を押すと冒険画面内に商品一覧が開き、購入後は「街のコマンドへ戻る」で閉じます。もちもの画面は「もちもの・素材・スキル」の3タブです。品揃えは街ごとに異なり、先の街で上位の道具・装備を購入できます。買った装備は「もちもの」から装着します。スキルはLv.2（火花の魔法・鼓舞）・3・5・7で習得し、魔法は賢さで強くなります。「スキル」でコマンドを一覧に切り替え、詳細を確認してからフィールドの敵（攻撃）・味方の状態欄（回復）をクリックして発動します。「戻る」で元のコマンドへ戻れます。全滅時は最後に訪れた街へ戻ります。

進行はこのブラウザへ自動保存します。端末間同期はありません。右上の設定メニューの「リセット」→「OK」でセーブを消去します。「キャンセル」では保持します。

## 道具の味方選択（2026-11-07）

戦闘・街・道中で道具を選ぶと冒険画面へ移り、味方の状態欄を押してHP/MPを回復できます。満タン・戦闘不能・不正な対象は使用不可。戻る・Esc・画面切替では道具とターンを消費しません。戦闘では開始メッセージの確認後に対象と残数を再検証し、回復と1個の消費を反映します。セーブ形式は維持。実装はdist/party.jsのvalidItemTarget/applyItem/useItem、ブラウザ検証はtests/e2e/item-target.spec.cjsです。


### 道具使用後の対象選択（2026-11-07）

使用後も同じ道具の対象選択を保持し、残数を表示します。残数0でも画面にとどまり、味方ボタンを無効化して選び直しを案内します。「戻る」・Esc・画面切替で終了。戦闘では1回の使用で1行動を消費し、後続行動中は再使用不可、次の主人公の番で再び対象を選べます。戦闘終了・主人公戦闘不能では選択を解除します。選択状態は保存しません。


## 戦闘メッセージのクリック範囲（2026-11-07）

メッセージ待機中は、冒険画面の背景・敵の絵・暗くなった攻撃や道具などのコマンド部分もクリック／タップで1件先へ進めます。主人公の入力待ちでは通常のコマンド操作へ戻ります。味方の状態欄・画面切替・設定は送り対象外。Enter・スペースの操作と保存形式は維持します。


## うんのよさと会心の一撃（2026-11-07）

うんのよさは旅団共通でLv.1に10、レベルごとに2上昇します。仲間の個別詳細・記録へ表示。物理ダメージスキル（現在は流星斬り）使用時に1回、`min(0.5, max(0, うんのよさ) / 512)` で会心を抽選します。Lv.5で約3.52%、Lv.30で約13.28%。通常攻撃・仲間の自動攻撃・敵攻撃・魔法・回復は対象外。会心時は「会心の一撃！」を結果メッセージとログへ表示します。

会心ダメージは `max(0, floor(攻撃力 × (0.9 + 0.2 × r) × スキル威力))`（rは0以上1未満）。守備力を無視し、攻撃力0・威力0なら0。通常時の物理式は維持。ドラクエの守備無視・攻撃力基準を参考にした独自調整で、特定作品の完全再現ではありません。

計算はdist/combat.jsのphysicalDamage、抽選と結果はshared/rules.jsのskillResult、表示はdist/party.js/game.jsに集約。成長設定はrules.growth.baseLuck/luckPerLevel（省略時10/2）で、旧公開定義・キャッシュ・戦闘中の定義にも適用します。不正な設定は共通バリデーターが拒否。公開済みDB定義は編集しません。保存キーとv:2を維持し、既存レベルから能力を算出するため進行データの書き換えは不要です。

検証はnpm testとtests/e2e/luck.spec.cjs。会心の確率境界・上限、守備無視、通常攻撃/魔法の対象外、MP消費、開始確認前のHP/MP保持、結果メッセージ、再読込の互換を確認します。PC幅・スマホ幅のスクリーンショットとコンソールも確認し、スマートフォン実機とは区別します。

## 戦闘中のステータスポップアップ（2026-11-09）

戦闘中の主人公の通常コマンド入力待ち、または非戦闘時の通常操作中に、フィールドの味方4人の顔画像・名前・HP/MP欄をクリックすると、その人のステータスをポップアップで確認できます。HP・MP・攻撃力・守備力・賢さ・素早さ・うんのよさを仲間詳細と共通の表示で示します。「閉じる」・Escで戻り、HP/MP・道具・ターンは消費しません。戦闘不能の仲間も確認可能です。

## 攻撃力上昇バフと特技「鼓舞」（2026-11-09）

Lv.2で「鼓舞」を習得します（MP4・戦闘専用）。スキル一覧から選び、生存中の味方1人をクリックすると、行動開始メッセージの確認後に攻撃力が1.5倍になります。自分にも使え、HP満タンでも対象にできます。対象者の通常攻撃・仲間の自動攻撃・物理ダメージ特技とその会心に適用し、魔法・回復・敵や他の味方の攻撃には影響しません。実効攻撃力は基本攻撃力×倍率を切り捨てた値です。

継続は残り3ターン。全員の行動が終わるターン終了時に1減り、付与したターンでは減りません。同種の効果は重ならず、再使用で残り3ターンへ更新します。0になると解除し、戦闘不能・勝利・逃走・全滅でも解除します。次の戦闘へは持ち越しません。

効果中の味方は画像上辺の小さな「剣↑」アイコンと残数で確認できます。状態欄のポップアップと「仲間」の個別詳細には、バフ名・攻撃力倍率・残りターンを表示し、攻撃力欄も補正後の値になります。通常の詳細を開けるタイミングとメッセージ送りは従来どおりです。道具・回復スキル・鼓舞の対象選択中は、味方クリックを対象指定に使います。

バフとMPは行動開始メッセージを送るまで変化せず、反映直前に対象とMPを再確認します。対象が戦闘不能になった場合などはMPを消費せず見送ります。戻る・Esc・非戦闘使用・MP不足も消費なし。ターン境界の既存自動保存へ効果と残数を含め、戦闘中の再読み込みは従来と同じ確定済みターンから再開します。古いセーブはバフなしとして読み込み、進行を消去しません。
