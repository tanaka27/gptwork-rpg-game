# 星灯りの旅団 — Starlight Chronicle

日本語で遊べる、オリジナルのターン制ブラウザRPGです。

- [ゲームを開く](https://starlight-chronicle-rpg.tomo27tomo84.chatgpt.site)（Sites・現在は所有者限定）
- [GitHub](https://github.com/tanaka27/gptwork-rpg-game)（開発ブランチ：`main`）

## 実装済みの内容

- 線でつながる12ノードのマップと、宿屋・ショップを備えた3つの街
- 通常モンスター12種類、ボス3種類、ターン制バトル
- レベルアップ、攻撃力・守備力・賢さ、物理／魔法の4スキル
- 武器・防具の購入と装備、回復アイテム、討伐依頼
- 11種類の素材、4段階のレアリティと確率ドロップ、素材売却
- 自動保存、旧セーブの移行、確認付きのヘッダーリセットボタン
- レスポンシブ表示と任意の効果音

## 起動方法

ビルドや依存パッケージは不要です。`dist/` を静的配信します。

```sh
python3 -m http.server 8080 --directory dist
```

ブラウザで `http://localhost:8080` を開きます。`dist/index.html` の直接表示も可能ですが、セーブは同じオリジンで扱うため、開発はローカルサーバーを推奨します。Google Fontsを取得できない場合はシステムフォントで表示します。

## 遊び方

世界地図の旗が現在地です。接続されたノードを選んで移動し、探索で魔物と戦います。各エリアで4体倒し、ボスのノードに行くとボスに挑めます。ボス撃破で次のエリアが解放されます。

街で宿泊・買い物・素材の売却ができます。買った装備は「もちもの」から装着します。スキルはLv.2・3・5・7で習得し、魔法は賢さで強くなります。全滅時は最後に訪れた街へ戻ります。

進行はこのブラウザへ自動保存します。端末間同期はありません。ヘッダーの「リセット」→「OK」でセーブを消去します。「キャンセル」では保持します。

## 検証

Node.jsで実行します。パッケージのインストールは不要です。

```sh
node --check dist/combat.js
node --check dist/game.js
node tests/game.test.cjs
```

ロジックテストは通過済みです。2026-11-04にローカルブラウザで320〜1440px幅の横あふれ、地図の展開、探索・攻撃・ターン進行を確認しました。詳細は[開発手順](docs/DEVELOPMENT.md)を参照してください。
