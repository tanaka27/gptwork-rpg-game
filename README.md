# 星灯りの旅団 — Starlight Chronicle

日本語で遊べる、オリジナルのターン制ブラウザRPGです。

- [ゲームを開く](https://starlight-chronicle-rpg.tomo27tomo84.chatgpt.site)（Sites・現在は所有者限定）
- [GitHub](https://github.com/tanaka27/gptwork-rpg-game)（開発ブランチ：`main`）

## 実装済みの内容

- 線でつながる12ノードのマップ、戦闘・素材入手などが起きる3工程の道中、宿屋・ショップを備えた3つの街
- 通常モンスター12種類、ボス3種類、最大4人対4体・素早さ順のターン制バトル
- レベルアップ、攻撃力・守備力・賢さ、物理／魔法の4スキル
- 武器・防具の購入と装備、回復アイテム、討伐依頼
- 11種類の素材、4段階のレアリティと確率ドロップ、素材売却
- 自動保存、旧セーブの移行、確認付きのヘッダーリセットボタン
- 画面内で冒険・地図・もちもの・記録を切り替えるUIと任意の効果音

## 起動方法

Node.js 24以上を使用します。

```sh
npm ci
npm run content:sync
npm run dev
```

`http://127.0.0.1:4173/`がゲーム、`/admin/`がデータ管理画面です。ローカルDBは`.local/rpg.sqlite`へ作成し、マイグレーションを適用します。Playwrightは専用の`work/playwright.sqlite`を使い、普段のセーブには触れません。

本番は既存SitesのWorkers/D1で動作します。[データ管理画面](https://starlight-chronicle-rpg.tomo27tomo84.chatgpt.site/admin/)は所有者としてChatGPTにサインインして開きます。`npm run build`はフロントとAPIを含む`build/server/index.js`・ホスティング設定・DBマイグレーションを生成します。`dist/`の静的配信でも同梱定義によるローカルプレイは可能ですが、データ管理・クラウド保存にはAPIが必要です。

## データ管理と保存

右上の設定から「データ管理」を開き、公開版を下書きへ複製して編集します。キャラクター・モンスター・装備・スキル・マップ・ショップ・成長/戦闘設定を編集し、検証→保存→プレビュー→公開できます。公開済みの版は編集せず、以前の版の再公開も可能です。参照中のデータ削除は検証で拒否します。JSONの取り込み/書き出しにも対応します。

通常の進行は従来どおりブラウザへ自動保存します。「クラウドセーブ」から明示的にDBへ保存・復元できます。クラウド更新前の進行はDBの履歴へ、復元前のローカル進行はブラウザのバックアップへ残します。クラウドの既存データを無確認で上書きしません。リセットはこのブラウザの進行を対象とし、クラウドのバックアップは残ります。

定義プレビューは通常の進行とは別の保存キーを使用し、クラウドへ保存しません。戦闘中の定義をセーブへ保持するため、再読み込み中に公開データが変わってもその戦闘は同じ定義で続けます。

## 遊び方

画面下部の「地図」で世界地図、「もちもの」で装備・素材・スキル、「記録」で能力・依頼・ログを開きます。長い一覧は画面内でスクロールできます。世界地図の旗が現在地です。接続されたノードを選ぶと道中に出発します。冒険画面の「先へ進む」3回で到着し、途中で戦闘・何もなし・素材入手のいずれかが起きます。道中の戦闘は最大1回で、勝利・逃走後に続きを進められます。戦闘中以外は出発地へ引き返せます。到着した探索地では「探索する」で魔物と戦います。各エリアで4体倒し、ボスのノードに行くとボスに挑めます。ボス撃破で次のエリアが解放されます。

街で宿泊・買い物・素材の売却ができます。街名は背景の上部に表示し、宿泊成功の回復メッセージは街の画面に表示しません。街の「お店」を押すと冒険画面内に商品一覧が開き、購入後は「街のコマンドへ戻る」で閉じます。もちもの画面は「もちもの・素材・スキル」の3タブです。品揃えは街ごとに異なり、先の街で上位の道具・装備を購入できます。買った装備は「もちもの」から装着します。スキルはLv.2・3・5・7で習得し、魔法は賢さで強くなります。「スキル」でコマンドを一覧に切り替え、詳細を確認してからフィールドの敵（攻撃）・上部の味方（回復）をクリックして発動します。「戻る」で元のコマンドへ戻れます。全滅時は最後に訪れた街へ戻ります。

進行はこのブラウザへ自動保存します。端末間同期はありません。右上の設定メニューの「リセット」→「OK」でセーブを消去します。「キャンセル」では保持します。

### Playwrightによるブラウザ検証

Node.js 24以上・npm・Python 3を用意し、次を実行します。アプリを遊ぶだけならインストール不要です。

```sh
npm ci
npx playwright install chromium
npm run test:e2e
```

PC・スマホ幅で画面切替、画像、はみ出し、戦闘と保存を確認します。スクショは毎テスト取得し、失敗時はトレースも保存します。結果を見るには `npm run test:e2e:report`。環境固有のChromiumを使う方法とGit管理対象は[開発手順](docs/DEVELOPMENT.md#playwrightによるブラウザ検証)を参照してください。

仲間3人は自動攻撃します。戦闘開始後は全員が素早さ順に行動し、主人公の番が来た時点で敵とコマンドを選びます。結果メッセージを送ると次の行動へ進み、次ラウンドも同じ流れを繰り返します。主人公が戦闘不能なら入力を待たず、仲間が戦闘を続けます。防御は主人公が行動してからラウンド終了まで有効です。味方全員のHPと素早さ、敵4体と行動順を表示します。

下部の「仲間」を開くとキャラクターが縦に並びます。1人を選択して詳しい能力を確認し、「仲間一覧へ」で戻れます。


戦闘中は、行動・勝利・報酬のメッセージごとにウィンドウをクリック（スマホではタップ）すると次へ進みます。「クリック / タップで次へ ▾」が目印です。Enter・スペースでも操作できます。


戦闘では、まず行動の開始メッセージを表示します。クリックするとその行動のダメージ・回復を反映し、結果のメッセージを送ると次の行動へ進みます。

## 道具の味方選択（2026-11-07）

戦闘・街・道中で道具を選ぶと冒険画面へ移り、上部の味方を押してHP/MPを回復できます。満タン・戦闘不能・不正な対象は使用不可。戻る・Esc・画面切替では道具とターンを消費しません。戦闘では開始メッセージの確認後に対象と残数を再検証し、回復と1個の消費を反映します。セーブ形式は維持。実装はdist/party.jsのvalidItemTarget/applyItem/useItem、ブラウザ検証はtests/e2e/item-target.spec.cjsです。


### 道具使用後の対象選択（2026-11-07）

使用後も同じ道具の対象選択を保持し、残数を表示します。残数0でも画面にとどまり、味方ボタンを無効化して選び直しを案内します。「戻る」・Esc・画面切替で終了。戦闘では1回の使用で1行動を消費し、後続行動中は再使用不可、次の主人公の番で再び対象を選べます。戦闘終了・主人公戦闘不能では選択を解除します。選択状態は保存しません。
