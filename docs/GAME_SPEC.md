# ゲーム仕様

この文書を現行ゲーム仕様の正本とします。初期ゲーム定義は `content/game.json`、共通の能力・戦闘計算と定義互換処理は `shared/` にあります。公開中のゲーム定義がある場合は、その定義を使って遊びます。

## 基本進行

線でつながる場所を旅し、探索地で魔物と戦い、経験値・ゴールド・素材を集めて装備を整え、各エリアのボスを倒します。3体のボスを倒すとクリア演出が入り、その後も探索を続けられます。

新規開始はLv.1、30 G、風そよぐ草原（`meadow`）です。旅人の剣（`twig`）と旅人の服（`cloth`）を装備し、いやし草（`herb`）3個、星のしずく（`ether`）1個を所持します。初期復帰先は、はじまりの村（`home`）です。

### 道中

目的地を選ぶと出発し、冒険画面で「先へ進む」を3回選ぶと到着します。各工程で次の出来事を1つ抽選します。戦闘は道中につき最大1回です。

| 出来事 | 戦闘前 | 戦闘後 |
| --- | ---: | ---: |
| 通常戦闘（敵4体） | 30% | 0% |
| 素材を1個入手 | 25% | 25% |
| 何事もなく進む | 45% | 75% |

道中のエリアは出発地と目的地のうち上位です。素材イベントでは、そのエリアの候補から等確率で1個を得ます。街の宿泊・購入・売却・依頼報酬は利用できませんが、回復アイテムと回復スキルは使えます。戦闘中以外なら出発地へ引き返せます。引き返しても、消費したHP/MP・道具・獲得素材は戻りません。到着した街が新たな救助先になります。道中と遭遇中の敵は自動保存され、再読み込み後も続けられます。

| エリア | 道中の素材候補 |
| --- | --- |
| 草原 | 澄んだ樹液、やわらかな毛皮、鋭い牙、精霊の種 |
| 遺跡 | 古代の石粉、月晶のかけら、月光真珠 |
| 火山 | 火山鉱、耐熱のうろこ、紅蓮石 |

道中素材の抽選は魔物のドロップとは別です。

## 戦闘

通常戦・ボス戦とも敵は4体です。ボス戦はボス1体と通常敵3体で構成します。味方4人と生存する敵が素早さの高い順に行動します。同速は味方を先にし、同陣営では隊列順です。

| 陣営 | 素早さ |
| --- | --- |
| 味方 | 人物ごとの初期値 + `Lv - 1` |
| 敵 | `8 + エリア番号 × 4 + 敵の隊列位置 × 3` |

各人の番にプレイヤーが「こうげき・スキル・どうぐ・ぼうぎょ」を選びます。「どうぐ」から逃走も選べます。戦闘不能者は行動せず、主人公が倒れていても生存する仲間の番では入力できます。行動者のMP・攻撃力・賢さ・うんのよさを使い、敵攻撃を受ける味方の守備力を参照します。通常攻撃の対象が解決前に倒れた場合は生存敵へ切り替えます。攻撃特技は解決直前に対象を再検証し、無効ならMPを消費せずその行動枠を見送ります。敵は生存する味方から対象をランダムに選びます。

行動は「開始メッセージ → クリック/タップで確認 → 効果を反映 → 結果メッセージ → 確認」の順です。メッセージ待機中は冒険画面の背景、暗くなったコマンド、味方状態欄、メッセージ窓のクリック/タップ、Enter、スペースで次へ進みます。画面ナビと設定は送り操作の対象外です。開始メッセージを送るまでHP/MP・道具・バフは変化しません。反映直前に行動者・対象・MP・所持数を再確認し、無効なら資源を消費せず見送ります。メニュー表示、選択の取消、コマンド受付時の条件不足、満タンへの回復は行動を確定せず、再選択できます。行動確定後の再検証で無効と判明した場合は、MPや道具を消費せず、その行動枠を見送って次の行動へ進みます。各行動の結果を確認するまで次の行動へ進みません。

### 物理攻撃、会心、防御

通常攻撃と敵の攻撃は威力1の物理攻撃です。物理スキルは特技表に記した威力を使います。`CombatRules.physicalDamage` が攻撃力・守備力・威力を用いて計算し、強攻撃と防御の倍率を適用した後に一度だけ切り捨てます。

```text
A = max(0, 攻撃側の攻撃力)
D = max(0, 受け手の守備力)
B = max(0, A / 2 - D / 4)
r = 0以上1未満の乱数

A = 0 または威力 = 0 の場合、ダメージ = 0
会心時: H = A × (0.9 + 0.2 × r)       （守備力を無視）
通常時、B >= 1: H = B × (0.9 + 0.2 × r)
通常時、B < 1: H = r < 0.5 なら0、それ以外は1（かすり当たり）
ダメージ = max(0, floor(H × 威力 × 強攻撃倍率 × 防御倍率))
```

通常の乱数倍率は0.9以上1.1未満です。基準値が1未満の通常攻撃は0または1のかすり当たりになり、最終値には威力・強攻撃・防御倍率も適用されます。最低ダメージは0です。守備力が攻撃力を超えても、攻撃力の2倍未満なら基準値は正です。

物理ダメージ特技は、使用者のうんのよさにより会心を抽選します。会心率は `min(0.5, max(0, うんのよさ) / 512)` です。会心は物理ダメージ特技だけに発生し、通常攻撃・敵攻撃・魔法・回復は対象外です。攻撃力が0または特技の物理威力が0なら会心しません。

防御は使用者本人だけに有効で、その人の行動後からラウンド終了まで受けるダメージを0.35倍にし、MPを3回復します（最大MPまで）。先行する敵の攻撃には適用されません。3ターン目ごとの敵攻撃は強攻撃となり、威力を1.4倍にします。強攻撃と防御は併用されます。

「鼓舞」「気合い」は対象者の実効攻撃力を `floor(基本攻撃力 × 1.5)` にします。通常攻撃・本人の物理ダメージ特技・その会心へ適用し、魔法・回復・敵・他の味方の攻撃には適用しません。効果は3ターンです。付与したターンの終了時は減らさず、その後は各ラウンドの終了時に1ずつ減らします。同じ種類の効果は重ならず、再使用で残り3ターンへ更新します。死亡、勝利、逃走、全滅で解除し、次の戦闘へ持ち越しません。「鼓舞」は生存中の味方1人（自分も可）、「気合い」は使用者本人だけを対象にします。

### 魔法・回復、道具、逃走

魔法ダメージと魔法回復は使用者の賢さだけから計算します。対象者の能力、攻撃力、武器補正、乱数は使いません。回復量は対象者の最大HPまでで、戦闘不能者は回復対象にできません。

```text
魔法の効果量 = max(0, floor(base + max(0, 使用者の賢さ) × power))
```

回復スキルは「もちもの」から人物を選んで使えます。戦闘中は行動者に固定され、装備変更はできません。回復スキルはHPが減っている生存者が対象です。道具はHPまたはMPが減っている生存者1人を選びます。道具と所持数は旅団共通です。非戦闘時は同じ道具の対象選択を続けて使えます。戦闘中は1回の使用でその人の行動を消費し、次の人の番で再度選べます。

通常戦闘では逃走を選べ、成功率は70%です。失敗してもその人の行動を消費し、後続の順番へ進みます。ボスを含む戦闘からは逃げられません。

全員が戦闘不能になると所持金の15%（切り捨て）を救助費として失い、最後に訪れた街で旅団全員のHP/MPを回復して再開します。経験値・装備・素材・所持品は保持します。勝利時は倒した各敵のEXP・ゴールド・素材を1回ずつ得ます。通常戦の戦闘不能者はHP1で復帰します。レベルアップまたはボス撃破時は旅団全員がHP/MP全回復します。

装備レアリティはノーマル／レア／エピック／レジェンドの4段階です。レア・エピック・レジェンドは追加効果を1・2・3個持ち、装備中の人物の能力へ固定加算します。基礎補正と追加効果は別に表示します。ショップにはノーマルとレアだけが並び、エピックとレジェンドは通常魔物のドロップ専用です。草原は `iron`、遺跡は `leather` / `eclipse_robe`、火山は `star` / `starlight_blade` が候補です。装備の詳細は「もちもの」またはショップから開けます。

| ID | 消耗品 | 効果 | 価格 |
| --- | --- | --- | ---: |
| herb | いやし草 | HP45回復 | 12 G |
| ether | 星のしずく | MP18回復 | 22 G |
| potion | 生命の霊薬 | HP全回復 | 40 G |

どの街でも宿泊でき、10 GでHP/MP全回復します。所持金が10 G未満なら無料で各人を最大値の半分（切り上げ）以上まで回復します。すでに半分より多い能力値は減りません。累計5体討伐すると、任意の街で一度だけ100 Gと生命の霊薬2個を受け取れます。

ゲームはブラウザのlocalStorageへ自動保存します。保存キーは `starlight-rpg-v1`、形式は `v:2` です。既存セーブの進行とこのキー・形式を維持し、互換用の変更で進行を消去しません。仲間の個別装備は `companions[].weapon/armor` に保存します。旧セーブでは人物IDを優先し、IDがない形式は隊列順で移行します。仲間の記録がない旧セーブには、各人の上限HP/MPで仲間を追加し、既存の仲間のHP/MPは保持します。旧形式の主人公の装備を初回だけ継承します。旧HP/MPが新しい上限を超えていても、読み込み・防御・宿泊で切り捨てません。宿泊・救助・レベルアップ・ボス撃破時は各人の上限まで回復します。

戦闘開始時の定義は `battleContent` としてセーブに保持されます。戦闘中に公開定義が変わっても、その戦闘には保存時の定義を使います。旧 `battleContent` に標準ジョブ・特技が欠ける場合は、現在の互換補完を適用した同じ定義を実行時と状態の両方へ同期し、以後の既存セーブ経路でも保持します。`GameContent.withJobs` の補完は非破壊であり、明示されたカスタム内容や衝突するIDを上書きしません。セーブ形式は変更しません。

設定メニューからリセットを選ぶと確認を表示します。「OK」でこのブラウザの進行を消去し、「キャンセル」またはEscでは保持します。通常の人物選択や画面選択はセーブしません。

## 画面操作

冒険、地図、もちもの、仲間、記録の5画面を下部ナビから切り替えます。「もちもの」にはもちもの・素材・スキルのタブがあり、「仲間」では一覧から人物を選んで詳細を開きます。味方の顔・名前・HP/MP欄を押すと、通常操作中にその人物のステータスを確認できます。戦闘中は味方のコマンド入力待ちに限り確認でき、戦闘不能の仲間も開けます。閉じる/Escで戻り、ターン・道具・HP/MPは消費しません。対象選択中、スキル一覧/詳細、行動やメッセージの待機中はステータス表示を開きません。

画面構成・配色・画像の利用規約は[UIデザイン指針](DESIGN.md)、キャラクター画像の仕様と再生成条件は[キャラクター画像](CHARACTER_ART.md)を参照してください。データ管理とAPIの説明は[文書索引](README.md)から該当する開発文書を参照してください。
