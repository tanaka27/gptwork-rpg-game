# キャラクター詳細のタブ化と装備詳細

- 状態：反映完了（GitHubのみ、Sites未反映）
- 設計版：v1
- 要求・背景：キャラクター詳細画面から装備を押して装備の詳細を見たい。詳細画面が縦に長すぎるので、タブで表示内容を切り替えたい（ユーザー依頼）。
- 設計作成者（子）：Claude Code

## 目的・受け入れ条件
- キャラクター詳細の見出し（顔画像・名前・Lv・状態・役割）の下に「能力・装備・特技・状態」のタブを置き、選んだタブの内容だけを表示する。
- 装備タブの武器・防具は押せる。押すとその場に装備詳細（レアリティ・部位・装備レベル・基礎補正・追加効果）を出し、「装備一覧へ戻る」で戻る。
- 「仲間」画面の詳細と、冒険画面で味方欄を押して開くステータス表示の両方で同じ動きにする。
- 選んだタブは別の人物を開いても保つ（比較しやすくするため）。装備詳細は人物を替えたら閉じる。
- タブはWAI-ARIAのtabsパターン（`role="tab"`・`aria-selected`・`aria-controls`・`role="tabpanel"`、左右・Home・Endキーで移動）に従う。
- PC幅・スマホ相当幅で、詳細がはみ出さず、ページ自体が横スクロールしない。

## 対象範囲
- 変更するファイル・機能：`dist/party.js`（詳細カードの構成、タブと装備詳細の切り替え）、`dist/game.js`（装備詳細の本文を共通化）、`dist/workspace.css`、`dist/index.html`・`dist/bootstrap.js`（キャッシュ用クエリ）、関連テスト、`docs/GAME_SPEC.md`・`docs/DESIGN.md`。
- 影響する既存仕様・関連文書：GAME_SPEC「画面操作」、DESIGN「背景とキャラクター画像」。
- 対象外：キャラクター詳細からの装備の付け替え（従来どおり「もちもの」で行う）、酒場NPC冒険者の詳細。

## 実装設計
- 変更内容：
  - 「もちもの」の装備詳細の本文（見出し・部位・装備レベル・基礎補正・追加効果）を `gearInfoMarkup(item)` に切り出し、もちもの・ショップとキャラクター詳細で共通に使う。
  - キャラクター詳細は4つのパネルをまとめて描画し、選択中以外は `hidden` にする。タブと装備詳細の切り替えはDOMの属性だけを変え、再描画は不要にする。再描画時も、選択中のタブと装備詳細はモジュール変数から復元する。
  - 能力：HP・MP・攻撃力・守備力・賢さ・素早さ・うんのよさ・会心率。装備：武器・防具（名前・レアリティ・基礎補正）。特技：固有特技。状態：バフ・状態異常。
  - IDの重複を避けるため、タブのIDは見出しID（`characterName` / `battleCharacterName`）を接頭辞にする。
- 既存セーブ・公開済み定義との互換性と移行：保存構造・定義は変更しない。
- 異常系・リスクと対策：装備がない（未知ID）場合は「なし」と表示し、押せる行にしない。
