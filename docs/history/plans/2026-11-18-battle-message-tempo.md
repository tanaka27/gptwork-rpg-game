# 戦闘メッセージのテンポ改善と「にげる」コマンド

- 状態：反映完了（GitHubのみ、Sites未反映）
- 設計版：v1
- 要求・背景：UXレビューで、1回の行動ごとに「〇〇の攻撃！」と「〇〇の攻撃！ △△に5。」の2回メッセージを送る必要があり、1ラウンドで十数回タップすると指摘した。逃走が「どうぐ」の中にあって見つけにくい点も指摘した。ユーザーから、メッセージ送りの削減、自動送りの追加、逃走の独立コマンド化を依頼された。
- 設計作成者（子）：Claude Code

## 目的・受け入れ条件
- 行動の宣言と結果を1件のメッセージにまとめ、1回の行動で送る操作を1回にする（例：「リナの攻撃！ リーフジェリーに5。」）。
- メッセージを一定時間で自動的に送る。自動送り中もクリック・タップ・Enter/Spaceですぐ次へ進める。
- 設定メニューで自動送りと手動送りを切り替えられる。初期値は自動送りで、選んだ値はブラウザに残る。
- 戦闘コマンドを「こうげき・スキル・どうぐ・ぼうぎょ・にげる」の5つにする。ボス戦では「にげる」を無効にする。「どうぐ」の一覧からは逃走を外す。
- PC幅とスマホ相当幅で、5つのコマンドが1行に収まり、文字が切れない。

## 対象範囲
- 変更するファイル・機能：`dist/party.js`（ログの統合、自動送り）、`dist/game.js`（戦闘コマンド、どうぐ一覧、設定メニュー）、`dist/index.html`（設定ボタン、キャッシュ用クエリ）、`dist/workspace.css`（5列のコマンド）、関連テスト、`docs/GAME_SPEC.md`、`docs/DESIGN.md`、遊び方の文。
- 影響する既存仕様・関連文書：GAME_SPEC「戦闘」「画面操作」、DESIGN「画面構成」。
- 対象外：勝利時の撃破・ドロップ・レベルアップのメッセージの統合（自動送りで負担が減るため今回は変えない）、戦闘以外のメッセージ。

## 実装設計
- 変更内容：
  - 宣言文は `announce()` で保留し、次の結果ログの先頭に付ける。結果ログが宣言文で始まる場合（通常攻撃・攻撃スキル・回復スキル・弱体スキル）は付けない。結果ログがないまま次の送りに入る場合は、宣言文だけを1件として出す。ぼうぎょは「〇〇は身を守る！」の1件にする。
  - 自動送り：メッセージを表示したら `900ms + 30ms×文字数`（上限2600ms）のタイマーで送る。手動で送ったときはタイマーを解除する。
  - 設定は保存データ（`starlight-rpg-v1`）とは別のlocalStorageキー `starlight-rpg-message-mode`（`auto` / `manual`）に保存する。読み書きの失敗時は自動送りとして扱い、例外を出さない。
  - 案内文は、手動時「クリック / タップで次へ ▾」、自動時「自動で進みます（タップで次へ）▾」。
  - 「にげる」は既存の `run` 処理をそのまま使う。
- 既存セーブ・公開済み定義との互換性と移行：保存構造は変えない。設定は別キーで、なければ自動送りにする。
- 異常系・リスクと対策：自動送りで既存テストの送り回数が不安定になるため、ロジックテストとE2Eは手動送りを既定にし、自動送りは専用のケースで確認する。

## 実装・検証結果
- 受け入れ条件と結果：
  - 宣言と結果の1件化：ロジックテスト（staged-actions・battle-messages・buffs）と、E2E（battle-flow・command-timing・damage-popup など）で、通常攻撃・特技・道具・ぼうぎょ・逃走・敵の行動が1件で表示・反映されることを確認。
  - 自動送り：`message-auto.spec.cjs` で、クリックなしに次の入力待ちまで進むこと、クリックで即座に送れること、手動へ切り替えると3秒待っても進まないこと、再読み込み後も設定が残ることを確認。ロジックテストでは待ち時間の計算と切り替えを確認。
  - 「にげる」：5コマンドが1行に並び文字が切れないこと、「どうぐ」に逃走が出ないこと、ボス戦で無効なこと、逃走の宣言と結果が1件で出ることをE2Eで確認。1440×900・390×844・320×568・844×390のスクリーンショットを目視し、ラベルが折り返さないことを確認。
  - `npm test` 成功。全E2E 120/120成功（game-desktop / game-mobile / admin-desktop / admin-mobile）。console/pageerrorなし。
- 設計との差異・未検証事項：
  - 鼓舞・気合いの結果文が「ガルドの気合い！ ガルドに気合い！」と重複するため、結果文を「〇〇の攻撃力が1.5倍に上がった（3ターン）。」に変更した。
  - 狭い幅で5コマンドのラベルが折り返したため、操作欄の幅に合わせて文字を縮める指定（`min(15px, 4cqi)`、折り返しなし）を追加した。
  - 既存テストの「宣言の確認前は効果を反映しない」という検証は、仕様変更に合わせて「表示と同時に反映し、送るまで次の行動へ進まない」に置き換えた。反映直前の再確認（対象が倒れていれば見送る）は、開始前に対象を倒した状態で確認する形に変えた。
  - iOS/Android実機とSitesでの動作は未確認。
- push・デプロイ結果：GitHub mainへpush。Sitesへは未反映（公開はCodexで行う）。
