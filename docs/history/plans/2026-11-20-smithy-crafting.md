# 鍛冶屋での装備作製

- 状態：反映完了（GitHubのみ、Sites未反映）
- 設計版：v1
- 要求・背景：鍛冶屋でドロップ素材とゴールドを消費して装備を作製する。作製可能な装備を一覧表示し、必要素材を持つものだけ選べる。作製品のレアリティはレア以上が確定。
- 設計作成者：Claude Code

## 目的・受け入れ条件
- 鍛冶の街ヴァル（`forge`）の街コマンドに「鍛冶屋」があり、開くとレシピ一覧（6種）を表示する。他の街・街の外・戦闘中・道中には出ない。
- 各行に装備名・装備Lv・基礎補正・必要素材（所持数/必要数）・費用を表示する。素材が足りないレシピは作製ボタンが無効。所持金不足・装備の所持上限（装着していない30本）でも無効（ボタン表記は「素材不足」「満杯」「◯ G」）。
- 作製すると素材とゴールドを消費し、装備1本を所持品に加える。レアリティはレア70%・エピック25%・レジェンダリー5%。追加効果の個数と数値は既存の `rules.gearRoll`（ドロップと同じ）。
- 処理側でも条件（場所・素材・所持金・上限・レシピの有効性）を検証する。

## 対象範囲
- 変更：`shared/crafting.js`（新規。固定レシピと作製処理）、`shared/rules.js`（`rollGear` にレアリティ確率の上書き引数）、`dist/game.js`・`dist/index.html`・`dist/workspace.css`（鍛冶屋UI）、`scripts/sync-content.cjs`、テスト起動用の読み込み一覧。
- 文書：GAME_SPEC（街・装備）、BACKEND（固定ルールの扱い）、HANDOFF（変更箇所）、CHANGELOG。
- 対象外：公開コンテンツ定義・データ管理画面でのレシピ編集、固有装備の作製、新規装備。

## 実装設計
- レシピ（ユーザー合意済み）：

| ID | 装備 | 素材 | 費用 |
| --- | --- | --- | ---: |
| craft_iron | 鉄のつるぎ | やわらかな毛皮×3、鋭い牙×2 | 120 G |
| craft_leather | 革のよろい | やわらかな毛皮×4、澄んだ樹液×2 | 100 G |
| craft_moon | 月守りのよろい | 古代の石粉×4、月晶のかけら×2 | 300 G |
| craft_moonsteel_blade | 月鋼の剣 | 月晶のかけら×3、月光真珠×1 | 600 G |
| craft_starward_armor | 星守りの鎧 | 古代の石粉×3、月光真珠×1 | 520 G |
| craft_star | 星銀のつるぎ | 火山鉱×4、耐熱のうろこ×2、紅蓮石×1 | 800 G |

- 依頼（`shared/quests.js`）と同じくゲーム側の固定ルールとし、公開定義に追加しない。参照先の装備が存在しない・固有装備・`rules.gearRoll` がない、または素材が定義にないレシピは一覧に出さず作製も拒否する（公開定義の差し替えへの耐性）。
- `CraftRules.check(state, data, id)` が `{ok, reason}`（`unavailable` / `materials` / `gold` / `full`）を返し、`craft(state, data, id, rng)` が検証後に素材・ゴールドを減らし `GameRules.addGear` 相当で抽選個体を加える。抽選は `GameRules.rollGear(data, baseId, rng, rarityRates)`。
- 装備レベルは作製条件にしない（購入・ドロップと同じ）。
- 作製結果は鍛冶屋の画面上部に装備詳細として表示し、ログに「（装備名）を作製した！［レアリティ］」を残す。
- 互換性：セーブ形式は変わらない。作製品は抽選範囲内のレア以上の個体なので、既存の `gearInstanceValid` / `SaveRules` の検証をそのまま通る。
