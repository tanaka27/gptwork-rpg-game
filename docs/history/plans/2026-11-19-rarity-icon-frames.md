# アイテムアイコンのレアリティ枠

- 状態：反映完了（GitHubのみ、Sites未反映）
- 設計版：v1
- 要求・背景：キャラクター詳細やもちもの画面のアイテムアイコンで、レアリティが一目で分かるよう枠か背景に色を付けたい（ユーザー要望）。
- 設計作成者：Claude Code

## 目的・受け入れ条件
- 装備画像（ショップ・もちもの一覧、もちもの/ショップの装備詳細、キャラクター詳細の装備一覧・装備詳細）がレアリティ色の枠で表示される。
- 素材アイコンもレアリティ色の枠と薄い背景で表示される。
- 既存の画像サイズ（40px/48px）・レイアウト・横スクロールなしを保つ。

## 対象範囲
- 変更：`dist/game.js`（`gearIconMarkup` に `gear-rarity-*` クラス）、`dist/workspace.css`、`dist/index.html`・`dist/bootstrap.js` のキャッシュ更新クエリ、E2E（`equipment-rarity`・`character-tabs`）、GAME_SPEC・DESIGN。
- 対象外：レアリティを持たない消耗品・スキルのアイコン。

## 実装設計
- `gear-rarity-<id>` で `--rarity-color` を定義し、`.gear-image` に2pxの枠を付ける。atlasはRGBで透過がないため、背景色ではなく枠と光彩（レア・レジェンダリー）で示す。画像がない追加装備は枠色を混ぜた背景にする。
- 素材の `.itemicon.rarity` は既存の文字色（`currentColor`）を枠と薄い背景（`color-mix`）に使う。
- 互換性：セーブ形式 `v:2`・定義・API・DBは変更なし。`border-box` のため画像の外寸は変わらない。
