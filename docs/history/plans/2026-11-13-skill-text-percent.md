# 特技説明文の修正と物理威力の%表示

- 状態：反映完了（GitHubのみ、Sites未反映）
- 設計版：v1
- 要求・背景：物理特技の説明に「相手の守備力を無視します」と自動で付き、常に守備力を無視するように読める。物理威力が「2.4倍」と表示されている。ユーザーから、指摘箇所の修正と、物理威力を%で表示する依頼を受けた。
- 設計作成者（子）：Claude Code

## 目的・受け入れ条件
- 物理ダメージ特技の自動の追記が、会心のときだけ守備力を無視すると読める文になる。
- 物理ダメージ特技の威力を、戦闘のスキル詳細・もちもののスキル一覧・仲間詳細の固有特技で「威力240%」の形で表示する。
- 説明文（`desc`）の末尾に「。」があっても句点が二重にならない。
- 攻撃力アップの倍率（1.5倍）・魔法・回復の表示は変えない。

## 対象範囲
- 変更するファイル・機能：`dist/game.js`（`skillDescription`）、`dist/party.js`（`skillEffectDescription`）、`content/game.json`（物理特技4件の `desc`）、生成物の同期、キャッシュ更新用クエリ、`docs/GAME_SPEC.md`、E2E `luck.spec.cjs`・新規 `skill-text.spec.cjs`。
- 影響する既存仕様・関連文書：GAME_SPEC「固有特技」の説明文の規則。
- 対象外：戦闘計算、魔法・回復・バフの文言、管理画面、セーブ形式。

## 実装設計
- 威力の%表示は定義の `effects[0].power` から自動で作る（`Math.round(power × 1000) / 10`％）。`desc` には威力を書かない。
- 物理ダメージ特技の詳細文：`{desc}（威力N%）。うんのよさが高いほど会心の一撃が出やすく、会心の一撃は相手の守備力を無視します。` `desc` が空なら `威力N%。…`。
- `desc` 末尾の「。」は表示時に取り除く。
- 既存セーブ・公開済み定義との互換性と移行：DBの公開版や戦闘中の `battleContent` には旧文「威力2.4倍」を含む `desc` が残り得る。表示用に、`desc` の末尾にある「（・/。）（物理）威力X倍」だけを表示時に取り除き、威力は%で重複なく表示する。定義・セーブ・DBは書き換えない。
- 異常系・リスクと対策：`effects[0].power` は共通バリデーターが数値を保証している。末尾以外にある「倍」は取り除かない（誤削除を避ける）。
