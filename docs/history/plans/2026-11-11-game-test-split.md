# ゲームロジックテストの機能別分割

- 状態：反映完了（作業ブランチへpush済み）
- 設計版：v1
- 要求・背景：`tests/game.test.cjs`（48KB、617行、1つのasync関数）は、関係する部分だけ読むことができず、エージェントのコンテキスト消費が大きい。ユーザーの依頼で機能別に分割する。
- 設計作成者：Claude Code（ユーザー依頼による。Codexの親子承認フローは対象外）

## 目的・受け入れ条件
- テストの中身（assert、テスト手順、PASS表示）を変えずに機能別ファイルへ分ける。assertの数とPASSメッセージが分割前と一致する。
- `npm test` が引き続き全テストを実行し、1件でも失敗したら非0で終了する。

## 対象範囲
- 変更：`tests/game.test.cjs` を削除し、`tests/game/` に `boot.cjs`（起動ヘルパーと `flush`）、機能別の6ファイル、`run.cjs` を追加。`package.json` の `test`、`docs/DEVELOPMENT.md` のテスト説明。
- 対象外：製品コード、生成物、E2E、他のロジックテスト。

## 実装設計
- 元ファイルの共通部分（`boot`）を `boot.cjs` へ移す。本体は既存のPASS行の区切りで6つに分ける。セクションをまたいで使われていた `flush` は `boot.cjs` から共有する。
- `run.cjs` は `tests/game/*.test.cjs` を名前順に子プロセスで順に実行し、失敗時は例外で非0終了する。
- 互換性：セーブ・定義・APIへの影響なし。

## 検証計画
- 分割前後で、assertの数、PASSメッセージの集合、テスト本文（空行と `flush` 定義を除く）を比較する。`npm test` を実行する。
