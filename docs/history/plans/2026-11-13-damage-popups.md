# 敵ごとのダメージ数値表示

- 状態：反映完了（GitHubのみ、Sites未反映）
- 設計版：v1
- 要求・背景：ダメージを与えたとき、モンスターごとに数値が見えるようにしてほしいという依頼。全体攻撃の結果メッセージは平均値だけで、敵ごとのダメージが分からなかった。
- 設計作成者（子）：Claude Code

## 目的・受け入れ条件
- 味方の通常攻撃・単体攻撃特技で、攻撃した敵の上にだけ与えたダメージの数値が表示される。
- 全体攻撃では、生存していた敵それぞれの上にその敵へのダメージが同時に表示され、会心の敵は区別できる。
- 数値は一定時間で消え、メッセージ送りなどの再描画で点滅・再生し直さない。
- 既存の戦闘メッセージ・ダメージ計算・セーブは変えない。

## 対象範囲
- 変更するファイル・機能：`dist/party.js`（ダメージ記録と敵ユニットへの数値挿入）、`dist/workspace.css`（数値の配置とアニメーション）、キャッシュ更新用クエリ（`index.html`・`bootstrap.js`）、`docs/GAME_SPEC.md`、`docs/DESIGN.md`、新規E2E `damage-popup.spec.cjs`。
- 対象外：敵から味方へのダメージ表示、回復量の表示、戦闘計算、セーブ形式。

## 実装設計
- ダメージを敵のHPへ反映した時点で `damagePopups`（敵の位置・数値・会心・記録時刻）を置き換える。表示は `render` が敵ユニットを描くときに、1.4秒以内の記録だけを `<span class="damage-popup">` として挿入する。
- `render` は1行動中に何度も呼ばれ、`#enemy` を作り直すため、`animation-delay` に経過時間を負の値で与えてアニメーションを途中から続ける。時刻は `Date.now()` を使う（ロジックテストのVMに `performance` がないため）。
- 戦闘開始時に記録を消す。敵ユニットの `aria-label` が名前を読み上げるため、数値は `aria-hidden`（数値はメッセージでも分かる。全体攻撃の内訳は視覚表示のみ）。
- `prefers-reduced-motion: reduce` では移動・拡大をせず、表示して消すだけにする。
- 既存セーブ・公開済み定義との互換性：保存対象に含めないため影響なし。

## 検証計画
- `damage-popup.spec.cjs`：通常攻撃で対象の敵にだけ数値、表示位置、消えた後の再描画で要素が消えること。全体攻撃で敵ごとの数値がHPの減少量と一致し、会心（乱数固定）の敵だけ `critical`。game-desktop／game-mobileで実行し、スクリーンショットを目視。
- `npm test` と全E2E。
- 対象外：iOS/Android実機（PC上のスマホ幅のみ）。Sitesへの反映はCodexが担当。
- 反映・復旧方法：`main` へpush。戻す場合はこのcommitをrevertする。
