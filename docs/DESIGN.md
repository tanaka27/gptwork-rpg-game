# UIデザイン指針

現在の画面構成と視覚表現を定めます。ゲームルールと数値は[ゲーム仕様](GAME_SPEC.md)、素材の保存先と制作条件は[キャラクター画像](CHARACTER_ART.md)を参照してください。

## 視覚ルール

濃紺 `#101820`、生成りの文字 `#eee7da`、セージの強調色 `#a5bf9f` を基本にします。見出しと主要な操作にはNoto Serif JP、数値と一覧にはNoto Sans JPを使います。細い区切り線と6〜8pxの角丸を用い、大きな囲みカードを重ねません。操作文字は14px前後を目安にします。

## 画面構成

ゲーム全体を画面高に収め、ページ自体はスクロールさせません。画面は下部ナビで切り替えます（画面の一覧と操作のルールは[ゲーム仕様](GAME_SPEC.md#画面操作)）。地図や長い一覧は各画面の内側でスクロールします。

冒険画面はフィールドの下端に味方4人の状態欄を置き、その直下に戦闘中は「こうげき・スキル・どうぐ・ぼうぎょ・にげる」の5コマンド、それ以外は4コマンドを横一列で並べます。5コマンドは狭い幅でもラベルを折り返さないよう、操作欄の幅に合わせて文字を縮めます（上限15px）。街名はフィールド上部に表示します。通常時の冒険メッセージはコマンド内、戦闘メッセージはフィールド内の味方欄の上に置きます。攻撃スキルの対象選択中は味方欄を隠して敵の領域を広げます。回復スキル、補助特技、道具の対象選択では味方欄を表示します。

スキル一覧は2列で、名前・種別・MPを示します。選択後は詳細と対象の案内を表示します。対象ダイアログは使わず、攻撃対象はフィールドの敵、回復や補助の対象は味方欄から選びます。全体攻撃の詳細表示では、生存中の敵全員に対象マーク（▼）を表示します。敵に与えたダメージは、その敵の絵の上に黄色の数値（会心は大きな橙色）を浮かべて示します。動きを減らす設定（`prefers-reduced-motion`）では、数値を動かさずに表示して消します。表示条件は[ゲーム仕様](GAME_SPEC.md)を正本とします。メッセージ送りとステータス表示の操作条件は[ゲーム仕様](GAME_SPEC.md)を正本とします。

低い横向き画面ではフィールドを左、操作欄を右へ置きます。狭い画面や画面高の小さい場合は、画像・一覧・メッセージの寸法を調整して操作部を画面内に保ちます。

## 背景とキャラクター画像

村と草原には水彩調の背景画像 `dist/assets/village.png`、`dist/assets/meadow.png` を使います。背景は表示する場面で読み込み、起動時に先読みしません（本番の配信形式は[DEVELOPMENT.md](DEVELOPMENT.md)）。上位エリアは背景の色調を変えて示します。敵は `dist/assets/monsters/{id}.png` の透過背景イラストを固定IDで表示し、フラットなアニメ調の全身絵を使います。モンスターはカードで囲まず画像と名前を直接表示し、追加定義の未登録IDは既存のSVG描画へフォールバックします。背景画像に文字、人物、敵、操作UIを含めません。

アステル、リナ、ガルド、ノエルは `dist/assets/characters/` の顔画像を、冒険中の状態欄と「仲間」画面の一覧・個別ステータス詳細で共通して使います。個別ステータス詳細は、顔画像・名前・年齢/性別・役割の見出しの下に4つのタブ（能力・装備・特技・状態）を均等幅で並べ、選択中のタブは金色の下線で示します。年齢と性別は名前の直下へ、12px以上の二次情報として表示します。タブはWAI-ARIAのtabsパターンに従い、左右・Home・Endキーで移動できます。装備タブでは武器・防具を部位・48px画像・名前・レアリティ・基礎補正の行として並べ、押すと同じパネル内で48px画像付き装備詳細に切り替えます。冒険画面で開くステータス表示も同じ構成です。ショップと「もちもの」の装備一覧にも40pxの画像を使います。標準装備の画像は `dist/assets/equipment-atlas.webp` のID別スプライトから選び、追加定義に画像がない場合は既存アイコンを表示します。画像は隣接する装備名と重複しない装飾として扱います。もちものの装備一覧の上には「並べ替え」「表示」の2つのセレクトを横に並べます（狭い幅では折り返す）。装備詳細の比較欄は、上昇を青 `#77baff`、下降を赤 `#ff8f8f` で示し、符号付きの数値も併記します。売却は詳細の最下部に置き、確定前に確認文と「売却を確定」「やめる」を表示します。装備画像（ショップ・もちもの・キャラクター詳細の一覧と詳細）は2pxのレアリティ色の枠で囲みます（コモン灰緑 `#8a9a91`、アンコモン緑 `#5fb89d`、レア紫 `#a58ce6`、エピック桃 `#df74b4`、レジェンダリー金 `#e8bf6c`）。レアとエピックは淡い光彩、レジェンダリーは強めの光彩を加えます。エピックのレアリティ文字は `#ee8fc6` です。画像がない追加装備は、枠色を混ぜた背景にします。素材アイコンは、レアリティ文字色と同じ色の枠と、その色を薄く敷いた背景で表示します。色は名前の横のレアリティ表記と併用し、色だけで区別させません。個別ステータス詳細では基本攻撃力に対する補正後の攻撃力を表示します。上昇中は青、下降中は赤、同じ値は通常色です。

酒場の冒険者100人はIDと同じ名前の `adventurer_001.webp` 〜 `adventurer_100.webp` を使います。一覧では72〜88pxの正方形枠に全身画像の頭頂から胸上を拡大表示し、選択後の酒場NPC冒険者詳細では同じ画像を全身表示します。詳細の名前直下に年齢・性別を表示します。「仲間」画面の4人の一覧・ステータス詳細とは別の表示です。

酒場内の「冒険者」「依頼」タブは左の縦サイドバーに置きます。酒場見出し、サイドバー、冒険者数は固定し、人物一覧だけを内側スクロールさせます。冒険者一覧は画像72〜88px、行高約96〜100pxを目安にします。下部の戻るボタンは右上の44px以上の「×」に置き換え、閉じた後は酒場コマンドへフォーカスを戻します。

## 操作とアクセシビリティ

操作は細い境界線と控えめな背景差で区別し、フォーカス時には明瞭なアウトラインを表示します。モンスターはカードで囲わず画像と名前を直接表示し、HPは数値なしのバーで示します。攻撃対象には矢印を表示します。HPバーの値は支援技術に割合として伝えます。

HPはセージ色、MPは青系で表示します。メッセージ窓は濃紺の半透明背景、明るい細枠、生成りの文字を使います。顔画像のaltや未知IDの扱いは[キャラクター画像](CHARACTER_ART.md)を正本とします。
