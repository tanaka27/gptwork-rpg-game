# UIデザイン指針

現在の画面構成と視覚表現を定めます。ゲームルールと数値は[ゲーム仕様](GAME_SPEC.md)、素材の保存先と制作条件は[キャラクター画像](CHARACTER_ART.md)を参照してください。

## 視覚ルール

濃紺 `#101820`、生成りの文字 `#eee7da`、セージの強調色 `#a5bf9f` を基本にします。見出しと主要な操作にはNoto Serif JP、数値と一覧にはNoto Sans JPを使います。細い区切り線と6〜8pxの角丸を用い、大きな囲みカードを重ねません。操作文字は14px前後を目安にします。

## 画面構成

ゲーム全体を画面高に収め、ページ自体はスクロールさせません。画面は下部ナビで切り替えます（画面の一覧と操作のルールは[ゲーム仕様](GAME_SPEC.md#画面操作)）。地図や長い一覧は各画面の内側でスクロールします。

冒険画面はフィールドの下端に味方4人の状態欄を置き、その直下に「こうげき・スキル・どうぐ・ぼうぎょ」の4コマンドを横一列で並べます。街名はフィールド上部に表示します。通常時の冒険メッセージはコマンド内、戦闘メッセージはフィールド内の味方欄の上に置きます。攻撃スキルの対象選択中は味方欄を隠して敵の領域を広げます。回復スキル、補助特技、道具の対象選択では味方欄を表示します。

スキル一覧は2列で、名前・種別・MPを示します。選択後は詳細と対象の案内を表示します。対象ダイアログは使わず、攻撃対象はフィールドの敵、回復や補助の対象は味方欄から選びます。メッセージ送りとステータス表示の操作条件は[ゲーム仕様](GAME_SPEC.md)を正本とします。

低い横向き画面ではフィールドを左、操作欄を右へ置きます。狭い画面や画面高の小さい場合は、画像・一覧・メッセージの寸法を調整して操作部を画面内に保ちます。

## 背景とキャラクター画像

村と草原には水彩調の背景画像 `dist/assets/village.png`、`dist/assets/meadow.png` を使います。上位エリアは背景の色調を変えて示し、敵の既存SVGはそのまま使います。背景画像に文字、人物、敵、操作UIを含めません。

アステル、リナ、ガルド、ノエルは `dist/assets/characters/` の顔画像を、冒険中の状態欄と「仲間」画面の一覧・個別ステータス詳細で共通して使います。個別ステータス詳細では基本攻撃力に対する補正後の攻撃力を表示します。上昇中は青、下降中は赤、同じ値は通常色です。

酒場の冒険者100人はIDと同じ名前の `adventurer_001.webp` 〜 `adventurer_100.webp` を使います。一覧では72〜88pxの正方形枠に全身画像の頭頂から胸上を拡大表示し、選択後の酒場NPC冒険者詳細では同じ画像を全身表示します。「仲間」画面の4人の一覧・ステータス詳細とは別の表示です。

酒場内の「冒険者」「依頼」タブは左の縦サイドバーに置きます。酒場見出し、サイドバー、冒険者数は固定し、人物一覧だけを内側スクロールさせます。冒険者一覧は画像72〜88px、行高約96〜100pxを目安にします。下部の戻るボタンは右上の44px以上の「×」に置き換え、閉じた後は酒場コマンドへフォーカスを戻します。

## 操作とアクセシビリティ

操作は細い境界線と控えめな背景差で区別し、フォーカス時には明瞭なアウトラインを表示します。モンスターはカードで囲わず画像と名前を直接表示し、HPは数値なしのバーで示します。攻撃対象には矢印を表示します。HPバーの値は支援技術に割合として伝えます。

HPはセージ色、MPは青系で表示します。メッセージ窓は濃紺の半透明背景、明るい細枠、生成りの文字を使います。顔画像のaltや未知IDの扱いは[キャラクター画像](CHARACTER_ART.md)を正本とします。
