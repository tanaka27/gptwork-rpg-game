# UIデザイン指針

2026-11-06更新。フレームワーク追加ではなく、既存のHTML/CSS/JavaScriptへ一貫した視覚ルールを適用。

## 方向

濃紺 #101820、生成りの文字 #eee7da、セージの強調色 #a5bf9f。見出し・主要操作はNoto Serif JP、数値・一覧はNoto Sans JP。14px前後の操作文字と、細い区切り線、6〜8pxの角丸。大きい囲みカードや英語の操作サブラベルを減らす。

4人のHP・MPバー→拡大した風景（下端にメッセージウィンドウ）→2列コマンド→線画の下部ナビ。場所名・戦闘説明の独立した帯は設けない。道中の目的地・工程はメッセージウィンドウに短く表示する。音・遊び方・リセットは右上の設定メニュー。画面高さへ収める5画面切替は維持する。

## 画像

内蔵Image GenでUI全体のコンセプトを生成後、村と草原の背景を個別生成。実UIの文字・アイコン・操作・HPはHTML/SVGであり、画像化していない。画像はdist/assets/village.pngとmeadow.png。GitHub・Sites両方に同じファイルを含める。

背景プロンプト：静かな日本のインディーRPG向け、4:3の水彩・ガッシュ。青緑・藍・セージの抑えた色調、月、村の石橋・石造りの家・暖かい小さな窓、または草原の道と中央の開けた場所。UI・文字・人物・敵を含めない。

## 比較と意図的な差

コンセプトと実画面で背景色、明朝体、ステータスの細いゲージ、水彩画、2列ボタン、線画ナビ、余白と区切り線を比較。画像は同じ方向性で生成した別アセット。コンセプトの仮EXP数値は使わず実セーブの数値を表示する。風景の比率は画面高さに合わせ可変とし、低い横向きでは左右配置。敵のSVGは既存のゲーム素材として維持。上位エリアは背景の色調差で表示し、固有背景の描き下ろしは今後の範囲。

スマホ実機ではなく、PCの実ブラウザで390×844を基準に、320×568・768×1024・1440×900・844×390を確認する。コンセプトPNGの原寸は852×1846、基準の論理画面幅390pxへ換算して比較。テスト内容と公開記録はCHANGELOGを参照。

フィールド内のメッセージは濃紺の半透明背景・明るい細枠・生成りの文字。敵の選択ボタンはメッセージより上の領域へ収め、隠れないよう余白を予約する。低い画面ではウィンドウと敵画像を縮め、横長画面ではフィールドとコマンドを左右に配置する。長いメッセージはウィンドウ内だけでスクロールする。

スキル対象ダイアログは通常1列、低い横向き（高さ540px以下・幅600px以上）では2列。対象ボタンとキャンセルを画面内へ収め、継承されたボタンの上marginは対象一覧でリセットします。
