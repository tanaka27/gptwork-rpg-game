# 非戦闘時の味方ステータス表示

- 状態：検証済み
- 設計版：v1
- 設計作成者：/root
- 要求：非戦闘時も、フィールドの味方をクリックして既存のステータスポップアップを表示する。

## 目的・受け入れ条件

1. 探索地・街・道中で、通常操作中の味方4人の画像/名前/HP・MP欄から同じステータスを開ける。戦闘不能者も対象。
2. 閉じる/Escで元の味方へフォーカスを戻し、HP・MP・道具・ターン・道中進行・セーブを変更しない。
3. 回復スキル・道具の対象選択を優先し、スキル一覧/詳細の間は詳細ポップアップを開かない。戻ると詳細を開ける。
4. 戦闘時は主人公の通常コマンド入力待ちだけ開く既存仕様を維持。敵/仲間の自動行動・報酬待機中は開かず、味方クリックでメッセージを送る。

## 対象範囲・実装設計

- dist/party.js：canInspectBattleCharacterをcanInspectCharacterへ改名し、`!busy && skillMenuMode==='commands' && (state.enemy ? !!commandResolve : !roundActive)`を描画と処理で共有する。openBattleCharacterはopenCharacterStatusへ改名。表示・HTML属性・dialogの共通処理は既存のまま再利用する。
- 非戦闘でもbusy/roundActiveの間（勝利報酬の待機等）は開かない。回復対象選択のhealingSkill優先とメッセージのキャプチャ処理を維持する。
- bootstrap/indexのキャッシュ番号更新。日本語ヘルプ・README・GAME_SPEC・HANDOFF・DEVELOPMENT・CHANGELOGを最新仕様へ更新。過去の設計書は履歴として維持。
- API・計算式・セーブキー/形式・定義・閲覧範囲は変更しない。新しい永続状態やデータ移行なし。
